# DEINDE Enterprise Solutions

Responsive, buildless website prepared for Corbin's GitHub and Vercel accounts.

## Preview

Serve `dist` with any static server. No package install or build is required.

## Deploy under Corbin's ownership

1. Create a repository in `DeindeEnterpriseSolutions` and upload this folder's source, excluding `.openai` (internal preview configuration).
2. Import that repository in Corbin's Vercel account.
3. Select framework **Other**, leave the build command empty, and use output directory `dist`. The included `vercel.json` sets this directory.
4. Review the generated deployment before connecting a domain.

## Content and behavior

- Uses the original supplied logo and the teal/navy brand palette.
- Google Fonts serves Montserrat and Open Sans; system fallbacks are provided.
- Services follow the phased business plan. Later service lines are identified as planned.
- Inquiry form opens a mailto draft to `cjsmith410@gmail.com`; it does not store inquiries or claim to send them. The visitor must send the draft in an email app. Direct email is available too.
- No analytics, cookies, tracking scripts, payment collection, or backend are installed.
- Confirm program availability, founder credentials, and final public copy with Corbin before launch. No nonprofit tax-exemption claims, performance statistics, testimonials, or credential-provider affiliations are published.
